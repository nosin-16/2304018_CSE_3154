## 1. Introduction

Web programming means building websites and web applications. In our first lab class, the course teacher gave us a general idea of the course: what we will learn, which tools we will use, and what we have to submit at the end. No program was written in this session, but it set the base for all the experiments ahead.

### 1.1 Objective
The objectives of this experiment were:
- To get a basic idea of the Web Programming sessional course.
- To know which technologies we will use in the lab.
- To learn about GitHub and the course outline.
- To understand what is expected in the final project.

### 1.2 Technologies Introduced
Our teacher told us that we will work with four main technologies in this course.

**HTML (HyperText Markup Language)** is used to build the structure of a web page. Headings, paragraphs, links, images, tables and forms are all created with it.

**CSS (Cascading Style Sheets)** is used to design the page. It controls colors, fonts, spacing and layout, and helps make a page look good on different screen sizes.

**JavaScript** is a scripting language that runs in the browser. It makes a page interactive by handling user actions, checking form inputs and updating content without reloading the page.

**PHP (Hypertext Preprocessor)** is a server-side language. It processes form data, runs the logic of the website and connects the web pages to a database.

### 1.3 GitHub
Our teacher also introduced us to GitHub, an online platform built on Git for version control and teamwork. With GitHub we can store our code in repositories, keep track of every change, work with others on the same project and share our work easily. We will use it to manage and submit our lab work during the course.

### 1.4 Course Outline
The teacher went through the course outline and explained how the semester will go. We will begin with HTML and CSS, move on to JavaScript, and then learn PHP and server-side programming.

### 1.5 Final Project
At the end of the sessional course, every student has to submit a project to the teacher. The project should be based on what we learn in the lab, using HTML, CSS, JavaScript and PHP together.

## 2. Discussion

This first class gave me a clear picture of the course. I understood that the four technologies work as a team: HTML builds the structure, CSS styles it, JavaScript adds behavior on the user's side, and PHP handles the work on the server. I also realized that GitHub is a very useful tool for keeping my code organized and safe. Since we have to submit a project at the end, I can start thinking about ideas early and practice regularly, so that I am not in a hurry at the last moment.

## 3. Conclusion

The experiment introduced us to the Web Programming course, the technologies we will use (HTML, CSS, JavaScript and PHP), GitHub, the course outline and the final project requirement. This knowledge will help me follow the upcoming experiments and prepare well for the final project.
