Zone Based Vehicle Speed Limiter

A wireless speed limiting system for a vehicle. The remote unit uses an nRF24L01 module with increase and decrease buttons and four limit-changing buttons to set the speed limit for each zone. The receiver unit gets the limit through its own nRF24L01 module (with adapter) and controls a DC motor through an L298 motor driver using an Arduino, so the speed never goes above the limit of the current zone.

Technologies used

  • Arduino (2 boards: remote and receiver)
  • nRF24L01 wireless modules with adapter
  • L298 motor driver
  • DC motor
  • Push buttons (increase, decrease and 4 limit buttons)
  • 10 µF capacitors (2)
